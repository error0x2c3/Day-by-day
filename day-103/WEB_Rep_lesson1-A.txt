1) Recover all books
Requête :
GET /books HTTP/1.1
Host: api.ecommerce.com
Accept: application/json
Authorization: Bearer token
User-Agent: Depend

Corps de la requête : Aucun
Code de statut attendu : 200 OK


2) Recover a specific book
Requête :
GET /books/{id} HTTP/1.1
Host: api.ecommerce.com
Accept: application/json
Authorization: Bearer token
User-Agent: Depend

Corps de la requête : Aucun
Code de statut attendu : 200 OK ou 404 No Found

3) Creating a new book
Requête :
POST /books/{NewId} HTTP/1.1
Host: api.ecommerce.com
Accept: application/json
Authorization: Bearer token
User-Agent: Depend

***Corps de la requête***
{
  "id": 150,
  "name": "Macbook M2",
  "price": 1499.99,
  "category": "Informatique"
}
Code de statut attendu : 201 OK ou 400 Malformed request

4) Update an existing book
Requête :
PUT /books/Id HTTP/1.1
Host: api.ecommerce.com
Accept: application/json
Authorization: Bearer token
User-Agent: Depend

***Corps de la requête***
{
  "id": 123,
  "name": "Ordinateur portable",
  "price": 9.99,
  "category": "Informatique"
}
Code de statut attendu : 200 OK ou 404 Not Found

Corps de la requête : Aucun
